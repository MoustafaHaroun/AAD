\section{System Context (C1)}
The Trade2 system enables users to exchange skills and communicate with others in their local neighbourhood.
Users interact with the system to perform actions such as creating listings, discovering listings, and messaging other users.

In addition to user interaction, the system depends on external services to support its operation.
A monitoring system is used to collect logs and metrics, allowing administrators to observe system behaviour and ensure availability.
