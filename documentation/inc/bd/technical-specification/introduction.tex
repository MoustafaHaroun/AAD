\section{Introduction}\label{sec:introduction}
This document describes the backend software architecture of \textit{Trade2}, a mobile application designed to help retired elderly people combat social isolation and loss of purpose by connecting them with neighbours to exchange skills and knowledge.

The document follows the C4 model and details the architectural decisions made during the design and development of the backend system.
This documentation covers the backend architecture of Trade2, including its system context, container structure, component design, deployment strategy, and testing approach.
The scope is limited to the backend software architecture and specifically focuses on the \emph{Robustness \& Availability} advanced track, which encompasses zero-downtime deployment, comprehensive monitoring and logging, and data consistency through transaction management.
