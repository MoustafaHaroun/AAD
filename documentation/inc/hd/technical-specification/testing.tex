\section{Test Cases and Report}\label{sec:hd-testing}

The front-end's test cases, execution report, and requirement coverage matrix are maintained in a standalone document, the \emph{Hybrid Development --- Test Plan} (\texttt{doc/hd/test-plan.tex}), rather than duplicated here. It covers all functional requirements from \cref{sec:hd-functional-requirements} with manual test cases (the front-end has no automated test suite), plus a handful of cases documenting known gaps found while reviewing the current implementation.
