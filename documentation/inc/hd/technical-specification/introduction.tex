\section{Introduction}\label{sec:hd-introduction}
This document describes the design of the front-end of \textit{Trade2}, a mobile application that helps retired elderly people combat social isolation and loss of purpose by connecting them with neighbours to exchange skills and knowledge.

It covers the problem the application solves, its stakeholders, the functional, non-functional, business, and user requirements, user stories, the use case diagram, the system context, container, and component architecture of the mobile application, the libraries used, wireframes and navigation, and the test cases and report.
