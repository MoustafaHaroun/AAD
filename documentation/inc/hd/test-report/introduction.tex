\section{Introduction}\label{sec:hd-testreport-introduction}

This document is the test report for the front-end of Trade2, the mobile application built as part of the Hybrid Development track. It records the execution of the functional test cases defined in the companion Test Plan document, which verify the front-end functional requirements defined in the \emph{Requirements} section of the Technical Specification, and maps every requirement to the test case(s) that cover it.

\subsection{Scope}\label{sec:hd-testreport-scope}

The front-end currently has no automated test suite (no unit, component, or end-to-end tests are configured in the Expo project). Every test case here is therefore executed by hand, on-device, against a running instance of the app and the backend API, rather than by a test runner.

\subsection{Out of scope}\label{sec:hd-testreport-out-of-scope}

User requirements U1--U14 are referenced by the Technical Specification but are not yet defined anywhere in this repository (they originate from a separate Design Essentials deliverable), so no test cases are derived from them here. Non-functional requirements beyond NFR1 are likewise marked as not yet defined in the Technical Specification's \emph{Requirements} section and are not covered.
