\section{Introduction}\label{sec:hd-testreport-introduction}
This document records the execution and outcomes of the manual test cases defined in the \tradesq{} Front-End Test Plan. It documents the actual test environment, the result assigned to each executed test case, observed behaviour that differs from the expected result, supporting evidence where available, and the resulting coverage of the front-end requirements defined in the Technical Specification.

The test report should be read together with the \tradesq{} Front-End Test Plan. The test plan defines the test approach, required test environment, test cases, pre-conditions, execution steps, expected results, and planned requirement coverage. This report does not repeat those definitions. Instead, it records how the tests were carried out in practice, what behaviour was observed, and whether the tested build satisfies the requirements within the scope of manual functional testing.

Test cases are recorded as Passed, Failed, Blocked, or Not run. A Passed result indicates that the observed behaviour matched the expected result. A Failed result indicates that the observed behaviour differed from the expected result. A Blocked result indicates that the test could not be completed because a prerequisite, required test data, or part of the test environment was unavailable. A Not run result indicates that the test case was not executed during the reported test period.
