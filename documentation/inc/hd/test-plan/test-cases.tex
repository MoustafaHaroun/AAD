\section{Test Cases}\label{sec:hd-testplan-test-cases}
This section defines the manual test cases that a tester should execute to verify the front-end functional requirements and selected non-functional requirements of the \tradesq{} Mobile Application. Each test case provides a unique identifier, a short name and description, the requirement or requirements it covers, the required pre-condition, the ordered steps to perform, the intended end condition, and the expected result.

Before executing a test case, the tester should confirm that its pre-condition is satisfied and prepare any required accounts, listings, notifications, network state, device settings, or other test data. The tester should perform the steps in the stated order, compare the observed behaviour with the expected result, and record the outcome as Passed, Failed, Blocked, or Not run in the separate test report. Where the observed result differs from the expected result, the tester should record the deviation and any relevant evidence, such as screenshots, error messages, reproduction steps, or device and API details.


\begin{htable}[caption = {TC001}, label = {tc:001}, presep = 1em, postsep = 2em]{colspec={lX}}
    Test Case ID & TC001 \\
    Name & Register a new account with valid data \\
    Description & A new user successfully creates an account through the registration wizard. \\
    Requirements & FR1 \\
    Pre-condition & The \tradesq{} Mobile Application is installed and the user is on the Landing screen; the email address used is not already registered. \\
    Steps & \parbox{\linewidth}{
        \begin{enumerate}
            \item Tap Register.
            \item Enter a unique email address and a password meeting the policy: at least eight characters, including lowercase, uppercase, a digit, and a special character. Confirm the password.
            \item Continue and enter the first and last name.
            \item Continue and enter the address fields.
            \item Continue and optionally skip the profile-photo step.
            \item Tap Create account.
        \end{enumerate}
    } \\
    End condition & The account exists and the user is signed in. \\
    Expected result & The application signs the new user in automatically and navigates to the Home screen. \\
\end{htable}
