Requirements not listed above are not covered by an on-device test case, for one of the following reasons:

\begin{itemize}
    \item \textbf{Not implemented in the current app}: FR18 (no indicator distinguishes a pending-sync change from a synced one; offline listing changes are simply disabled rather than queued), NFR17 (no per-item cached-vs-confirmed indicator exists beyond the global offline banner), and NFR20 (the front-end has no automated test suite).
    \item \textbf{Not verifiable through app interaction alone}: NFR1--NFR4, NFR7, NFR9, NFR10, NFR14, NFR16, and NFR19 describe implementation details (transport scheme, secure-storage usage, API contracts, technology stack, cross-platform build, cached-data classification, static analysis) or design-review judgment calls (touch target sizing) that a tester cannot confirm or deny purely by using the app on a single device.
    \item \textbf{Implemented but not exercised by a dedicated test case}: NFR6 (the API client maps backend error responses to their plain-language \texttt{message} field instead of showing the raw response body).
\end{itemize}
